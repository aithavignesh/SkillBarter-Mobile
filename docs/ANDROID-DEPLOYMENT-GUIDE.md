# SkillBarter Mobile: Android Deployment & Release Guide

## 1. Overview
This document outlines the deployment configuration, build architecture, and exact steps to build and distribute the standalone installable **SkillBarter Android APK** (Preview) and the **Android App Bundle (AAB)** (Production for Google Play).

- **Framework:** React Native `0.76.9` + Expo SDK `52.0.37`
- **Routing:** Expo Router `~4.0.17`

- **Bytecode Engine:** Hermes (`hermesc.exe` bytecode pre-compilation enabled)
- **Application ID:** `com.skillbarter.mobile`
- **Version Code:** `1` (Version `1.0.0`)
- **Build Infrastructure:** Expo Application Services (EAS Build Cloud)

## 3. Build Profiles Configuration (`eas.json`)

The project is configured with three distinct build profiles:

```json
{
  "cli": {
    "version": ">= 12.0.0"
  },
  "build": {
    "development": {
      "developmentClient": true,
      "distribution": "internal",
      "env": {
        "EXPO_PUBLIC_API_URL": "http://10.0.2.2:4000/api/v1"
      }
    },
    "preview": {
      "distribution": "internal",
      "android": {
        "buildType": "apk"
      },
      "env": {
        "EXPO_PUBLIC_API_URL": "https://api.skillbarter.com/api/v1"
      }
    },
    "production": {
      "android": {
        "buildType": "app-bundle"
      },
      "ios": {
        "simulator": false
      },
      "env": {
        "EXPO_PUBLIC_API_URL": "https://api.skillbarter.com/api/v1"
      }
    }
  },
  "submit": {
    "production": {}
  }
}
```

### Profile Breakdown
1. **`preview` (Downloadable Android APK):**
   - **Target:** Standalone installable `.apk` file.
   - **Distribution:** `internal` (direct download link generated by EAS).
   - **Use Case:** Direct installation and testing on physical Android devices without requiring Google Play Store.
   - **API Target:** `https://api.skillbarter.com/api/v1` (Production API endpoint).
2. **`production` (Google Play Store AAB):**
   - **Target:** Android App Bundle (`.aab`).
   - **Distribution:** Google Play Console internal testing / production track.
   - **Optimizations:** Dynamic feature delivery, device-tailored APK generation by Google Play.
3. **`development` (Expo Dev Client):**
   - **Target:** Custom dev client for emulator debugging with local API routing (`10.0.2.2:4000`).

## 5. How to Trigger EAS Android Cloud Build

Because EAS Build runs in Expo's secure cloud infrastructure, no local Android Studio, SDK, or NDK installation is required on your machine.

### Step 1: Authenticate with Expo (One-Time)
Run either of the following commands in your terminal:

**Option A: Interactive Login via Web Browser**
```bash
npx eas login
```

**Option B: Non-Interactive CI Token (Recommended)**
If you prefer not to open a browser, create a personal access token at [expo.dev/settings/access-tokens](https://expo.dev/settings/access-tokens) and run:
```bash
# In PowerShell:
$env:EXPO_TOKEN="your-expo-token-here"

# In Bash / macOS / Linux:
export EXPO_TOKEN="your-expo-token-here"
```

### Step 2: Initialize EAS Project (If first time)
```bash
npx eas project:init
```
This links the repository to your Expo organization/account and generates your unique `projectId` in `app.json`.

### Step 3: Trigger the Downloadable APK Build (Preview)
```bash
npx eas build --platform android --profile preview
```

### Step 4: Obtain the APK Download URL
Once the EAS cloud runner finishes (typically 4–8 minutes):
1. The terminal will display:
   ```
   ✔ Build finished
   Android APK: https://expo.dev/artifacts/eas/...apk
   ```
2. You will also receive an install page URL (e.g. `https://expo.dev/accounts/[user]/projects/skillbarter-mobile/builds/[build-id]`) featuring:
   - A direct **Download APK** button.
   - A **QR Code** that testers can scan with their Android phone camera to download and install immediately.

### Step 5: Trigger the Google Play Store AAB Build (Production)
When ready to submit to the Google Play Console:
```bash
npx eas build --platform android --profile production
```
This outputs a signed `.aab` file ready for upload to Google Play Internal App Sharing or Production Track.

## 6. Android User Installation Instructions (Sideloading APK)

Share these instructions with team members and beta testers:

1. **Download the APK:**
   - Open the EAS build link or scan the QR code on your Android device.
   - Tap **Download anyway** when Chrome/browser prompts *"File might be harmful"*.
2. **Enable Unknown Apps Installation:**
   - When opening the `.apk`, if prompted by Android:
     - Tap **Settings**.
     - Toggle on **Allow from this source** for your browser (Chrome/Files).
3. **Install the Application:**
   - Tap **Install**.
   - Tap **Open** to launch **SkillBarter**.
4. **Permissions:**
   - Allow camera and storage permissions when uploading profile photos or skill media.
